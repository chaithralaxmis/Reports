# AlertOps Dashboard

A modern, responsive analytics dashboard built with React and Tailwind CSS. This project provides a clean interface for managing and visualizing report data with interactive charts and efficient listing features.

## ✨ Features

- **📊 Interactive Analytics**: Visualize data using responsive Bar and Doughnut charts powered by Chart.js.
- **📋 Report Management**: List, search, and add new report dashboards with ease.
- **📱 Fully Responsive**: Optimized for all screen sizes, from mobile to desktop.
- **📄 Efficient Navigation**: Built-in pagination and search functionality for large report lists.
- **🎨 Premium UI**: Styled with Tailwind CSS for a modern, high-quality aesthetic.

## 🛠️ Technology Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Charts**: [Chart.js](https://www.chartjs.org/) & [react-chartjs-2](https://react-chartjs-2.js.org/)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)

## 🚀 Getting Started

### Prerequisites

- Node.js (Latest LTS recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd reports
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## 📜 Available Scripts

- `npm run dev`: Starts the Vite development server.
- `npm run build`: Builds the application for production.
- `npm run lint`: Runs ESLint to check for code quality issues.
- `npm run preview`: Previews the production build locally.

## 📂 Project Structure

- `src/components`: Reusable UI components (Dashboard, ReportList, Modal, etc.).
- `src/assets`: Static assets and global styles.
- `public`: Static public assets.
